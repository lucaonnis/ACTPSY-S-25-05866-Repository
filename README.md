# Registered Report: Supplementary Materials and Analysis Code

## Overview

This repository contains the data, analysis scripts, and outputs associated with the Registered Report submitted for consideration in *Acta Psychologica*.

The repository is intended to support transparency and reproducibility by providing the materials required to understand the analyses reported in the manuscript and, where possible, reproduce the reported results.

The repository has been prepared for anonymous peer review. Identifying information has been omitted from this version.

## Repository structure

The repository is organised into the following directories:

| Directory | Contents |
|---|---|
| `R/` | R scripts used to prepare the data, conduct the statistical analyses, and generate results. |
| `BLP/` | Anonymised dataset and R scripts associated with the Bilingualism Language Profile (BLP) component of the project. |
| `data/` | Anonymised datasets used in the analyses of the experiment. |
| `figures/` | Figures generated during the analyses of the experiment. |
| `output/` | Intermediate and final analytical outputs, including processed datasets and summary results. |

The main RStudio project file (`.Rproj`) is provided in the repository's root directory.

## Getting started

The analyses were conducted using R and RStudio.

To access the project:

1. Download or clone the repository.
2. Open the `.Rproj` file in RStudio.
3. Ensure that the R packages required by the analysis scripts are installed.
4. Run the relevant scripts in the R/ directory in numerical order, following the sequence indicated by their filenames (e.g., 001.*, 002.*, ..., 01.*,  02.*, etc.).

The scripts are organised by analytical component. Please consult the individual scripts for details about the analyses they perform and the files they use.

**Note:** Some fitted model objects are not included in the public repository because of their file size. These objects can be regenerated by running the corresponding analysis scripts, provided that the required data and software dependencies are available.

## Data and confidentiality

The datasets included in this repository have been anonymised for research transparency and independent inspection.

Audio recordings and other materials not intended for public distribution are not included.

The repository should be used for research and reproducibility purposes in accordance with applicable data-use and research-ethics requirements.

## Analysis outputs

The `output/` directory contains intermediate and final outputs generated during the analysis workflow. These include processed data objects and summary results used to support the reported findings.

The `figures/` directory contains figures generated from the analyses.

## Reproducibility

The analysis scripts are provided to document the analytical workflow and facilitate independent verification of the reported results.

For full reproducibility, users should:

- Use the data files provided in the `data/` directory.
- Consult the relevant scripts in the `R/` directory.
- Check the individual scripts for required packages and analysis settings.
- Regenerate model objects where these are not distributed in the repository.

## Questions

For questions about the materials or analysis procedures, please refer to the accompanying Registered Report manuscript.
